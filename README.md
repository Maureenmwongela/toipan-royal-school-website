# Toipan Royal Girls High School Website

A responsive school website developed for Toipan Royal Girls High School using HTML and CSS.

## About the Project

This project provides an online presence for the school, helping parents, students, and prospective learners access information about the school and its services.

## Features

- **Home Page:** Introduction to the school and its educational mission.
- **About Page:** School background, vision, and motto.
- **Admissions Page:** Information for prospective students.
- **Facilities Page:** Information about school facilities.
- **Fees Page:** School fee information.
- **Contact Page:** School contact information and communication links.
- **Responsive Navigation:** Navigation designed to work across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- GitHub

## Project Structure

- `index.html` — Home page
- `about.html` — About the school
- `admissions.html` — Admissions information
- `facilities.html` — School facilities
- `fees.html` — Fee information
- `contact.html` — Contact information
- `style.css` — Website styling
- `images/` — Website images and logo

## How to View the Project

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Navigate through the website pages.

## Developer

Developed as a practical web development project to demonstrate HTML, CSS, website structure, and responsive design skills.
